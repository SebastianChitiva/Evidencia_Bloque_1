# Evidencia_Bloque_1

Proyecto en el cual se analiza información de ventas sobre productos y fabricantes con nombres genéricos. Esto se debe a que es información real de productos de la categoría de leches. 


En este reporte hacen lo siguiente

1. Extraer información de una base de datos de excel, la cual contiene venta, unidades, Precio por litro y por unidad de productos de leche. Estos están clasificados por fabricante y producto.
2. Se analiza esta base de datos, encontrando patrones, market share por producto y por fabricante en el transcurso de los años, matriz de correlación y covarianza de precios unitarios, entre otros.
3. Modelo de regresión logarítmica univariada para encontrar la elasticidad entre precio y venta de litros.
4. Modelos de regresión logarítmicos multivariados progresivos con el objetivo de mejorar la explicabilidad del precio respecto al volumen, analizando los coeficientes, estadístico t, p-values, Durbin-Watson, entre otros.
5. Desarrollo paso a paso del modelo y posibles modelos a utilizar para predecir volumen 24 meses a futuro.
